## Описание проекта

Графические аналоговые часы, разработанные на Python с использованием Tkinter.
Программа отображает текущее время компьютера и работает в реальном времени.

## Функциональные возможности

- Отображение текущего времени компьютера
- Обновление часов в реальном времени
- Отображение текущей даты
- Отображение текущей фазы Луны
- Интерактивный хронограф
- Запуск и остановка хронографа
- Сброс хронографа

## Установка и запуск

### 1.Клонировать репозиторий:

git clone https://github.com/vantuzov/simple-animation.git
cd simple-animation

### 2.Создать виртуальное окружение:

python -m venv venv

### 3.Запустить программу:

python main.py

## Пример использования

После запуска программы открывается окно с аналоговыми часами. Пользователь может просматривать текущее время, дату и фазу Луны, а также использовать хронограф.
